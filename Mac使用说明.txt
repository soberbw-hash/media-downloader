音视频下载器 · Mac 版
────────────────────────────

【这台软件给谁用】
  只给 Apple 芯片的 Mac（点左上角  → 关于本机，「芯片」写 Apple M1 / M2 / M3 / M4）。
  安装包只有一个，不用挑。Intel 芯片的 Mac 暂时用不了这个包，打不开而已；
  想用就去 GitHub 下源码，双击「启动.command」自己跑，功能一样。

【装】
  1. 双击 DMG，把「音视频下载器」拖进 Applications（应用程序）
  2. 第一次打开：在应用程序里对着图标点右键 → 打开 → 再点一次「打开」
     也可以打开「终端」，贴这一行后回车：
       xattr -dr com.apple.quarantine "/Applications/音视频下载器.app"
     然后正常双击就能开。

  为什么会有这一步：这个包没有交 Apple 开发者年费做签名和公证，
  macOS 对网上下载的软件都会先拦一下。只需要弄一次，以后不用管。
  看到「无法验证开发者」「已损坏，无法打开」都是这个原因，不是软件坏了。

【用】
  双击打开后会自动弹出一个软件窗口（也可能直接在浏览器里开标签页）。
  不用装 Python、不用装 Homebrew、不用装 ffmpeg，全都已经打进包里了。

  下好的文件默认在：访达 → 下载 → 音视频下载器
  想换地方：窗口右上角「设置」→ 下载目录。

  有些站点要登录（QQ音乐、Suno 等）：
  第一次用 →「账号」→「选中扩展文件夹」（地址会自动复制）→ 浏览器右上角 ⋮
  →「扩展程序」→「管理扩展程序」→ 打开「开发者模式」→「加载未打包的扩展程序」，
  弹窗里粘贴（Cmd+V）就到那个文件夹。
  之后点「打开」→ 在浏览器里登录 → 回来就是「已登录」。

【更新】
  有新版会自动下好、装好、重启，不用管。
  从 GitHub 下载安装包前先开 VPN / 代理，不然很慢。

【退出】
  关掉软件窗口不会停服务，右上角菜单里点「退出」才是真的关。
  再双击图标会接着用已开着的服务，不会开两份。

【数据放在哪】
  配置、下载记录、cookie：~/Library/Application Support/VideoDL
  卸载时把 .app 丢进废纸篓即可；上面那个文件夹留着不影响什么，
  想一起清掉也可以。

【有问题】
  窗口打不开、一直转圈：先看 ~/Library/Application Support/VideoDL/logs/boot.log
  还不行就把日志发给做这个软件的人。
