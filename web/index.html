这是什么？怎么获取？

它是什么。一个网址，作用只有一个：把视频号「分享链接」换成「视频直链」。 粘分享链接时，软件把链接发给它，拿回直链再下载。

为什么要它。微信只把视频地址发给带登录态的请求，分享链接里没有视频， 所以视频号没法像抖音那样开箱即用。

三条路，任选一条：

  1. 不填也能下（最省事）——拿到直链直接粘首页。 直链长这样：finder.video.qq.com/…/stodownload?…， 用任意能解析视频号的工具或网站换出这种地址就行，这个设置留空。
  2. 自己搭一个（一劳永逸）——照下面的接口约定做个几行的小服务， 把地址填上面。开源工具 wx_channels_download 自带解析服务， 还支持一键部署到 Cloudflare Worker，部署出来的网址直接填。
  3. 用现成的——同事、朋友或服务商给你的解析接口地址，填上面即可。

接口约定（给搭接口的人看）：

软件会 POST {"url": "分享链接"} 到这个地址 （也支持 GET ?url=，或地址里写 {url} 占位符）。 返回任意 JSON，只要含视频地址就行——字段叫 videoUrl / playable_url / url / src / video 都认，或者任何带 stodownload 的字符串。 可选 title / nickname 字段，软件会拿来命名文件。
