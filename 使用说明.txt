音视频下载器
============

启动
----
双击「诊断.bat」就行，没有第二种方式要挑（前台运行，报错会留在窗口里）。

开出来是一个没有地址栏的独立窗口，任务栏里单独一个图标，跟装好的软件
一样。窗口大小按你的屏幕自动算，小屏上不会顶出边界。
关掉这个窗口 = 退出，服务会一起停，不留后台进程。

（后台还有一个最小化的命令行窗口，那是服务本体，别手动关它；它最小化
  着不碍事。正常退出走界面右上角的「退出」或者直接关窗口。）

公司电脑打不了 exe 的话，这个 .bat 双击就能用，不用装任何东西。它用的是
机器上本来就有的 Edge 和 Python，没有新增任何可执行文件，所以不触发
「未签名程序」那类拦截。

万一哪台机器上编辑器起不来（比如浏览器被策略禁了），在命令行里执行

    start.bat web

会用默认浏览器开一个普通网页标签，功能完全一样，只是多了一圈浏览器界面。

如果双击没反应：说明没找到 Python 3.11+，命令行窗口里会有提示。

Mac 上怎么开
------------
mac 没有 .bat，用同一个目录里的「启动.command」，双击就行。
第一次可能被系统拦一下（「无法打开，因为来自身份不明的开发者」），
右键点它 → 打开 → 再点「打开」；或者在「系统设置 → 隐私与安全性」
底下点「仍要打开」。

先备好三样东西（终端里执行）：

    brew install python@3.12
    python3 -m pip install --user yt-dlp
    brew install ffmpeg

pip 那条要是报 externally-managed-environment，就在末尾加
--break-system-packages 再来一遍。

mac 的独立窗口靠 Chrome / Edge 的应用模式；机器上只有 Safari 的话会
变成普通标签页，功能一样，只是多一条地址栏。选文件夹用的是 mac 原生面板。


用法（一次贴一堆也行）
----------------------
主界面就一个大框，Ctrl+V 直接贴，贴什么都能认：

  · 抖音/小红书那种带一堆文字的分享内容 → 自动挑出链接
  · 一个框里塞十几条链接 → 自动拆成十几条任务
  · 不带 https:// 的短链（v.douyin.com/xxx、xhslink.cn/xxx）→ 也认
  · 一次粘一条 → 每次粘贴单独算一批，任务卡片上会标「第 N 批」

「粘贴即下载」开关默认打开：粘贴完立刻开始下，不用点按钮。
想先攒着一起看，就把开关关掉，贴完点「开始下载」或按 Ctrl+Enter。

打开软件时输入框已经聚焦好了，直接 Ctrl+V 就行；点到别处（比如刚点过某个
任务）再按 Ctrl+V 也认，只有正在填设置里的输入框时才按普通粘贴处理。

同样的链接贴第二次不会重复下载，会提示「这条已经在列表里了」。

输入框下面那行是支持的平台，屏窄的时候末尾会收成「+2」这样的按钮，
点一下展开全部，再点「收起」收回去。带黄点的表示要先登录或先配点东西。


图集（图文作品）
----------------
抖音的图文作品（链接里带 /note/ 的）、小红书的图文笔记、快手的图集，
贴进来会自动识别成图集，把整组图片全部下下来。

下完任务卡片里会展开成一片缩略图，这时候可以：
  · 单张保存   —— 鼠标移到图上，右下角出现 ↓，点一下就复制一份到下载目录
  · 勾选打包   —— 点图打勾（可以只挑几张），点「打包选中」，生成 zip
  · 全部 ZIP   —— 不挑，整组打成一个 zip
  · 全选 / 反选 —— 图多的时候用

任务卡片右边的小字：「打开」是打开文件所在文件夹（点已完成任务的标题也行），
「重试」只在失败或取消时出现，「取消」只在排队或下载中出现。

任务多的时候
------------
「任务」右边有四个筛选项：全部 / 进行中 / 失败 / 已完成，后面跟当前数量。
贴了二十条有一条没下来，点「失败」就只剩那一条，不用滚。

有失败时右上角会出现橙色的「重试失败 N」，一次把所有失败的重新排队——
断网、被限速这种，等网络好了点一下就行，不用一条条点。

下到一半断了（断网、关程序、点取消都算），点「重试」会从断点接着下，
不会重头再来。下了一半的文件都叫「xxx.mp4.part」这种名字，就是为了让你
一眼看出它是半截的；只有真正下完才会改成正式文件名。

窗口最小化着的时候，看任务栏上的标题就知道进度：
  ↓ 2/5 · 音视频下载器   正在下，完成 2 条、共 5 条
  ⚠ 3 项失败 · 音视频下载器   有 3 条下不来
  ✓ 5 项已完成            刚跑完，会闪 5 秒再变回原名

失败的那行红字是新写的：直接说「视频不可用：已删除、私密或地区限制」
这种，不再甩一串英文异常。鼠标停在上面能看到原始报错，要发给我排查时
把它复制下来就行。

几点说明：
  · 图片是去水印的。抖音的图片地址有两种，带 -water 的那批是打了「抖音号」
    水印的版本，程序取的是不带水印的那批。
  · 分辨率由平台给，有的图能到 2560 宽，有的只有 540，这个改不了。
  · 抖音图集存下来是 .webp 格式（平台就是这么发的）。Win11 自带照片、
    剪映、PS 2023 以后都能直接打开；要转 jpg 的话随便找个转换工具就行。


各平台情况（实测结果，不是猜的）
--------------------------------
能直接用
  抖音        无水印最高码率，走分享页解析；图文作品自动按图集下
  B站         1080P 以上要登录（见下面的账号登录）
  微博        单条微博 / 微博视频
  西瓜视频、AcFun、Vimeo、Twitch
  YouTube、X、TikTok、Reddit   需要代理（下面有说明）

Reddit
  支持 reddit.com / old.reddit.com / redditmedia.com 的帖子链接，
  以及 v.redd.it 直链。帖子必须是带视频的，纯图片帖会报「没有视频」。
  注意：Reddit 会拉黑机房 IP 和公共代理，报 403 就说明你这台机器的
  出口 IP 被它拒了，换一个能正常打开 reddit.com 的代理才下得了。

要登录
  小红书      必须登录。设置里点「登录」，扫码后自动保存，之后直接下
              （图文笔记同样是登录后才解析得到）
  快手        游客 cookie 能调 live_api，但成功率不稳，登录后明显更稳
              （图集走同一套接口）
  Instagram   需要登录 + 代理
  B站         登录后可下 1080P 以上画质

实验性
  新片场      走通用识别，能从页面里抓到视频就下，抓不到会报错

需要额外配一下
  视频号      别人的视频下不了，这是微信的限制（不是软件没做）
              自己的作品：设置 → 高级设置 → 视频号 → 点「打开视频号助手」，
              扫码登录后进 内容管理 → 已发布，某条右边「更多」→「下载视频」，
              下到的是官方原片，画质不打折。
              软件本身能下两种：直接粘 finder.video.qq.com 开头带 stodownload 的
              直链；或者你有解析接口，填进「我有解析接口（进阶）」里。

视频号为什么不能像抖音那样开箱即用
----------------------------------
抖音分享页里有 _ROUTER_DATA，游客就能拿到播放地址；视频号的视频流走的是
自研协议，未登录时服务器只发封面，不发视频。这不是解析写法的问题：

  · 分享链接 weixin.qq.com/sph/xxx 会跳到 channels.weixin.qq.com/finder-preview，
    这个预览页在浏览器里打开是**白页**——我用浏览器实测过，它连一个播放请求
    都不发，只在微信客户端里才工作。所以扫码登录网页也拿不到别人的视频。
  · 视频流还带解密 key，key 只发给微信客户端进程。
  · GitHub 上的方案（ltaoo/wx_channels_download 等）是往微信 PC 客户端里注入，
    或者装根证书做 MITM 代理——要管理员权限，公司电脑不建议。

所以软件里留的是「接口」这个口子：手上有能用的解析服务（自建 Worker、
付费接口、公司内部服务都行），填进设置就能通；没有就粘直链。

直链怎么来：任何能把视频号分享链接转成 finder.video.qq.com 直链的工具、
站点、小程序都行，拿到后粘进软件，下载和命名交给它。

其它站点（自动兜底）
  不在上面名单里的站点，会交给通用识别去试一遍。
  能抓到视频（页面里有 mp4 / m3u8）就能下，抓不到会明确告诉你下不了。
  实测：直接给 mp4 地址可以正常下载。


账号登录（重要）
----------------
设置 → 账号登录，每个平台一行，两种方式任选：

  点「登录」  弹一个真实的浏览器窗口（用你电脑上的 Edge），在里面扫码或
              输账号密码。登录成功后窗口自己关掉，cookies 存到 cookies\
              目录，之后下载自动带上。要换账号点「重登」。

  点「粘贴」  只有网易云和 QQ音乐有。不想开窗口，就把浏览器里已经登录的
              cookie 复制过来，粘进弹层保存。怎么复制：

                1. 浏览器打开 music.163.com 并登录（QQ音乐是 y.qq.com）
                2. 按 F12 → Application（应用）→ Cookies → 点对应域名
                3. 找到 MUSIC_U（QQ音乐是 qm_keyst 和 uin）
                4. 把「名字=值」那一串复制出来，粘进去

              嫌麻烦就用 Cookie-Editor 这类插件，Export → Copy，整段贴进来，
              什么格式都认（一行 key=value、Cookie: 开头、插件导出的 JSON、
              yt-dlp 那种 cookies.txt 都行）。

保存后会立刻去问一次：显示这个号的昵称，是会员就带「黑胶VIP / 绿钻」标记。
cookie 过期了会标红「已失效」，不会默默失效让你一直以为是登录状态。

注意：
  · 这个窗口用的是独立配置，不会动你平时用的 Edge 数据
  · Instagram 登录前必须先能在浏览器里打开 Instagram（即代理已配好）
  · 登录态有有效期，过期了重新点一次登录，或者重贴一次 cookie
  · cookie 只存在本机 cookies\ 目录，不上传、不同步


下载历史
--------
右上角「历史」里能看到所有下过的东西，关掉软件也不会丢（存在 history.json）。

  · 顶部搜索框可以按标题、作者、平台过滤
  · 点任意一条，直接打开它所在的文件夹
  · 「导出 CSV」把记录导到下载目录，Excel 双击就能开，带标题/作者/平台/
    时长/大小/时间/路径/原链接，方便做素材表
  · 「清空记录」只删记录，已经下好的文件不动

同一条链接如果以前下过、文件还在，再贴一次会提示「以前下过了」，不会重复占空间。
文件被你删了的话，照常重下。


音乐
----
顶部切到「音乐」，选平台、搜歌名或歌手，回车。

  · 网易云：不登录就能搜、能下大部分免费歌（320k）。贴上你自己账号的
            cookie 后，会员能拿无损 FLAC，VIP 曲也能下
  · QQ 音乐：必须登录（播放地址是登录后按账号下发的）。会员 cookie 能拿无损
  · 酷狗：能搜，但播放地址目前要登录态，先当搜索用

会员音质怎么生效（重点）
  贴完 cookie 后不用再选什么，跟着「设置 → 清晰度」走：
    最高画质          会员 → 无损 FLAC，非会员或没登录 → 320k mp3
    720p 及以下       320k mp3（省空间）
  无损拿不到会自动往下退（无损 → 320k → 128k → 免费外链），不会因为
  一首歌要会员就整批失败。

  无损是 .flac，文件名带歌名和歌手，但里面不写 ID3 标签（FLAC 不是这个格式）。
  mp3 照常把歌名、歌手、专辑、封面写进文件标签，播放器和资源管理器里都能看到。

下下来的 mp3 会把歌名、歌手、专辑和封面写进文件标签里，播放器、
资源管理器里都能看到封面，不是光秃秃一个文件名。

一次想下好几首：在结果列表左边勾选，或者点「全选」，再点右上角
「下载所选（N）」。勾选状态会跟着行高亮，点「下」还是单首。

直接粘单曲链接也行（music.163.com 那种带 #/song?id= 的分享链接也认）。
歌单/专辑链接目前不自动展开，得逐首挑——主页批量抓取还在做。

Apple Music 和 Spotify 做不了：前者的完整音轨有 DRM，iTunes 只开放 30 秒试听；
后者要靠 YouTube 找同名资源替换，准确率不行，先不碰。


设置项说明
----------
下载目录     第一次下载时会弹一个窗口让你选存哪儿，选完以后不再问。
             想改就打开「设置」，点输入框右边的「浏览…」，走系统自带的
             选择文件夹对话框；也可以直接手动填绝对路径，不存在会自动创建。
             默认是程序目录下的 downloads
命名模板     留空就用原标题。填了按模板改名，例如
             {date}_{platform}_{author}_{title}
             会变成 20261103_抖音_某某某_视频标题
             能用：{title} {author} {platform} {date} {time} {id} {kind}
             图集和音乐也一样生效
同时保存封面 打开后多一张「同名.cover.jpg」。音乐不用开，封面直接写在
             文件标签里了
顺便下字幕   打开后，B站 / YouTube 有 CC 字幕就存成 .srt。
             没有字幕的视频会跳过，不会报错
保存弹幕     B站弹幕存成同名 .xml（就是弹幕列表，PotPlayer、剪映都能直接
             挂上去看）。只有 B站有，其他平台跳过
保存简介     标题、作者、平台、链接、时长、大小、简介写成同名 .txt，
             日后翻素材不用回网页找
             这四样默认都是关的，要用哪个开哪个。开着的附件会收进一个跟
             视频同名的文件夹（文件夹跟着上面的命名模板走），下载目录里
             还是一排视频，不乱
音乐存到     留空 = 跟视频放同一个目录。填一个路径，音乐单独存
清晰度       最高画质 / 1080p / 720p / 仅音频(mp3)
             音乐走同一项：最高画质 = 有会员就拿无损（FLAC），
             720p 及以下 = 固定 320k mp3
             境外平台选「最高画质」容易拖到 4K 大文件，几百 MB，建议固定 1080p
同时下载数   一次贴很多条时的并发数，默认 3，网络差就调 2
代理         留空 = 境外平台自动用 Windows 系统代理，国内平台始终直连
             要指定就填 http://127.0.0.1:7890 这种格式
cookies 文件 一般不用填，用上面的账号登录就行；填了会优先用它
视频号解析接口 只在要下视频号时用。填一个能接受 POST {"url": "分享链接"} 的地址，
             返回 JSON 里带视频地址就行（字段叫 videoUrl / playable_url / url 都能识别）。
             留空 = 只支持粘 finder.video.qq.com 直链。
             这东西怎么来？设置里该项下面有「怎么获取？」，写了三条路：
               1) 不填接口，用别的工具把分享链接换成 finder.video.qq.com 直链再粘
               2) 自己照接口约定搭个小服务（开源工具 wx_channels_download 也能干这活，
                  还支持一键部署成 Cloudflare Worker，网址直接填）
               3) 用同事/服务商给的现成接口地址


代理与速度（实测）
------------------
在没填代理的情况下，YouTube / X / Reddit 这类平台会自动读 Windows
「Internet 选项」里的代理设置，所以公司电脑挂的公司代理也能直接用上，
不会再像以前那样一律超时。

但要注意：公司代理通常是按带宽限速的。本机实测通过公司代理下 YouTube
只有 20 KB/s 左右，一个 3 分钟视频选最高画质是 229 MB，按这个速度要下
三个多小时，实际上没法用。想正常下境外视频，还是得挂自己的代理/VPN，
在设置里填上它的地址（常见的是 http://127.0.0.1:7890）。


常见问题
--------
Q: 提示「这个站点没有专门的解析器」
A: 就是通用兜底也没抓到视频。要么页面是 JS 渲染的，要么需要登录。

Q: 小红书还是失败
A: 先在设置里登录小红书，再点任务上的「重试」。
   还不行就把分享链接原样发我 —— 链接里必须带 xsec_token。

Q: Reddit 报「直接拒绝了这台机器的网络出口（403）」
A: 不是链接的问题，是 Reddit 拒了你的出口 IP。它专门拉黑机房 IP 和
   公共代理，公司网络、云服务器上都容易中。换一个能正常打开
   reddit.com 的代理后再点重试。链接识别、下载逻辑都是通的。

Q: 抖音报「视频数据为空」
A: 图文作品走的是另一套数据，下不了。或者这条视频被删了。

Q: B站只有 720p
A: 1080P 以上需要登录。设置里登录 B站 账号即可。

Q: 进度条停在 99% 很久
A: B站这类是「视频流 + 音频流」分开下，最后要合并。等一会儿。

Q: 想改端口
A: 默认 8765，被占用会自动往后找。不用管。


文件说明
--------
诊断.bat             出问题排查用（前台运行，独立窗口，报错留在窗口里）
start.bat            启动逻辑本体（直接双击也是独立窗口；start.bat web 走浏览器兜底）
server.py            本地服务
core.py              解析与下载引擎（平台识别、链接抽取、任务队列）
cn_sites.py          快手 / 小红书专用解析
sph.py               视频号（直链下载 + 自定义解析接口）
music.py             音乐：网易云 / QQ 音乐 / 酷狗的搜索与下载，ID3 标签
login.py             账号登录，导出 cookies
picker.py            系统「选择文件夹」对话框
web\                 界面文件
cookies\             登录生成的 cookies（别外传）
config.json          配置，界面里改就行
history.json         下载历史。删掉它等于清空记录，已下的文件不受影响
downloads\           默认下载目录
