音视频下载器  v{VER}（免安装）
================================

打开
----
双击「音视频下载器.exe」。公司电脑如果拦住了，双击
「音视频下载器-公司」那个快捷方式，用起来一模一样。
什么都不用装，也不会往系统里写东西。

下载
----
复制一个视频 / 音乐 / 图集链接，回到窗口直接 Ctrl+V，就开始下了。
整段分享文案、一次贴好几条链接也认。
下好的文件在「下载的文件」文件夹里，右上角「下载目录」能直接打开。

搜索
----
点上面的「搜索」，可以搜歌、找音效、找视频素材、找电影，搜到点一下就下。

登录
----
绝大多数网站不用登录。少数平台要登时，右上角「设置 → 账号」：
第一次用：点「选中扩展文件夹」→ 浏览器右上角 ⋮ → 扩展程序 → 管理扩展程序
→ 打开开发者模式 → 加载未打包的扩展程序，选中刚才那个文件夹。
之后每个平台点「打开」→ 在浏览器里登录 → 回来就是「已登录」。

更新
----
有新版会自动下好、装好、重启，不用管。
从 GitHub 下载安装包前先开 VPN / 代理，不然很慢。

关掉窗口 = 退出，不留后台进程。
